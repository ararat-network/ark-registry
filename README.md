# ark-registry

The network registry for [Ark](https://github.com/ararat-network/ark): one description of every Ark network that the
app, the SDK, the explorer, and any wallet read instead of keeping their own.

| Path | Holds | Maintained |
| --- | --- | --- |
| `ark/`, `arktestnet/`, `arklocal/` | `chain.json` and `assetlist.json` in the [community chain-registry](https://github.com/cosmos/chain-registry) schema, and `ark.json` for what that schema has no field for | Generated by `ark`'s [contrib/registry](https://github.com/ararat-network/ark/tree/main/contrib/registry) at the ref in `ARK_VERSION` |
| `endpoints.json` | RPC, REST, gRPC, explorer, and indexer endpoints per network, merged into the generated files | By hand, here |
| `images/` | The brand kit's symbol, which `ark.json` points at | Generated |
| `chain.schema.json`, `assetlist.schema.json` | The community schemas the standard files validate against, unmodified copies from the chain-registry under CC-BY-4.0, see `NOTICE` | Pinned copies |
| `ARK_VERSION` | The `ark` ref the generated files describe | By hand, at each chain release |

## Two halves

The chain is the source of truth for what it stores: denominations and their exponents, the prefix and coin type,
the versions it is built from, and the genesis a network starts from. Those are generated from the chain's code and
artefacts and never edited here; the check below fails on any difference. The registry is the source of truth for
what the chain does not store: where the nodes are, which explorer to link, and which features a client may assume.

Mainnet's asset list holds only what its genesis registers, NOAH, until a vote registers the stablecoins, after which
the files are regenerated at the release that follows. The localnet entry carries the Docker localnet's ports and no
genesis hash, since its genesis is made on every init.

## Regenerate

From an `ark` checkout at the ref named in `ARK_VERSION`:

```sh
go run ./contrib/registry --out ../ark-registry --endpoints ../ark-registry/endpoints.json --version "$(cat ../ark-registry/ARK_VERSION)"
```

The check workflow does the same on every push and pull request and fails if the committed files differ. To change
an endpoint, edit `endpoints.json` and regenerate; to move to a new chain release, change `ARK_VERSION` and regenerate.

## For a consumer

Read `chain.json` for the chain ID, prefix, coin type, fee and staking tokens, versions, and endpoints, and
`assetlist.json` for every denomination's units and symbol. Read `ark.json` for the genesis hash, which tells a
client it reached the right network, the feature flags, the reference denomination and feeds, the fee denominations
the chain accepts, and the [fee contract](https://github.com/ararat-network/ark/blob/main/docs/clients/CLIENT_FEES.md)
that prices a fee in any of them. Logos live in `ark.json` rather than the standard files, whose schema admits only the
community registry's own image URLs.
